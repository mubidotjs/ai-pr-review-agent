# PRISM — AI PR Review Agent

PRISM is a read-only public pull-request reviewer built with React, TypeScript, Hono, a browser Web Worker and a bounded Node agent. It combines three conservative AST rules with model-selected investigation through five scoped tools. Exact added-line evidence is independently validated against pinned GitHub source before a proposal can become an approvable finding.

The release integration adds a native Cloudflare Gemma 4 adapter, authenticated live endpoints, atomic shared quota controls and human-approved Markdown. It preserves the working deterministic/offline interface and the original review limits. PR content is not persisted; no code is executed and nothing posts to GitHub.

**Verified so far:** local mocked-provider integration, deterministic finding/evidence parity, and protected deployed Node 24 transport with correctly scoped environment configuration. Incremental delivery and the 4,752,446-byte fixture passed previously; the final transport run also passed exact 12-MiB count/hash/EOF in 88.98 seconds, controlled incomplete framing, and server cancellation in 2.599 seconds. **Latest real-agent acceptance failed on decision 2:** one synthetic workflow made 2 native dispatches, accepted one `getPullRequest` decision, then exposed `INVALID_MODEL_RESPONSE` at the Cloudflare relay's assistant content/decision validation boundary. No findings were produced; approval/copy was not reached. No live GitHub review, retry or production release followed. All temporary resources and CLI access were removed. The engineering focus is evidence authority, conservative claims, bounded tools/cost, prompt-injection containment, partial coverage, transport integrity and human control. This is a limited review assistant, never a security clearance or autonomous publisher.

Offline analysis bounds valid framed ingestion below 8,126,464 bytes without changing any limit; the 12-MiB fixture is a transport stress case. The 120-second maximum client transfer deadline is separate from the unchanged 30-second server deadline. [Reproducible transport evidence](FINAL-RELEASE-ACCEPTANCE.md). Transport was not retested during the subsequent AI-only acceptance. One real tool-selection step is established; a completed AI review remains unverified.

The corrected protocol uses documented native Gemma function calling, compact hypotheses and backend-issued fact-card IDs. The backend owns every finding detail and revalidates final selections. Representative synthetic outputs and full offline tests precede separately authorized real acceptance.
