# PRISM — AI PR Review Agent

PRISM is a read-only public pull-request reviewer built with React, TypeScript, Hono, a browser Web Worker and a bounded Node agent. It combines three conservative AST rules with model-selected investigation through five scoped tools. Exact added-line evidence is independently validated against pinned GitHub source before a proposal can become an approvable finding.

The release integration adds a native Cloudflare Gemma 4 adapter, authenticated live endpoints, atomic shared quota controls and human-approved Markdown. It preserves the working deterministic/offline interface and the original review limits. PR content is not persisted; no code is executed and nothing posts to GitHub.

**Verified so far:** local mocked-provider integration, deterministic finding/evidence parity, and protected deployed Node 24 transport with correctly scoped environment configuration. Incremental delivery and the 4,752,446-byte fixture passed previously. The final authorized run additionally passed exact 12-MiB count/hash/EOF in 88.98 seconds, controlled incomplete framing, and server cancellation in 2.599 seconds. **Real-agent acceptance failed:** the first synthetic workflow made one native dispatch but returned `MODEL_ERROR`, with no validated decision or findings. No second workflow, live GitHub review or production release followed. All new resources and temporary credentials were removed. The historical basic native inference probe succeeded but does not prove this agent. [Actual results](release-acceptance-result.json) · [Release controls](RELEASE.md).

The engineering focus is evidence authority, conservative claims, bounded tools/cost, prompt-injection containment, partial coverage, transport integrity and human control. This is a limited review assistant, never a security clearance or autonomous publisher.

Offline analysis bounds valid framed ingestion below 8,126,464 bytes without changing any limit; the 12-MiB fixture is a transport stress case. The 120-second maximum client transfer deadline is separate from the unchanged 30-second server deadline. [Reproducible evidence and executed final acceptance scope](FINAL-RELEASE-ACCEPTANCE.md). Transport acceptance passed; the real-agent integration remains unverified beyond its failed first decision.
