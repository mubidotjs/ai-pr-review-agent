# PRISM — AI PR Review Agent

PRISM is a read-only public pull-request reviewer built with React, TypeScript, Hono, a browser Web Worker and a bounded Node review engine. The backend acquires GitHub evidence and prepares source windows, then one real-model adapter call selects supported kind/path/line hypotheses. Exact supplied added-line evidence is independently validated against pinned source before a proposal becomes a finding. The backend constructs severity, explanation, recommendation and source references; inference is never spent on routine metadata, inventory or source retrieval.

The native Cloudflare Gemma adapter, authenticated live endpoints, shared quota controls and human-approved Markdown preserve the deterministic/offline UI and original review limits. No PR code is executed or persisted, and nothing posts to GitHub. Browser findings cannot become server attestations.
